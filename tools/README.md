# Runtime tools

This directory is populated by `scripts/setup-tools.ps1`.

Run the setup script from the project root:

```powershell
./scripts/setup-tools.ps1
```

It downloads yt-dlp, FFmpeg, FFprobe, and Deno from their official GitHub repositories. Executables and generated source records are not committed to the source repository.
